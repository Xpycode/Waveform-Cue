# Appearance panes Wave 2 verification

On November 28, 2026 the M4 Pro running macOS 15.8.1 built and tested P2.1 and P2.2. The coordinator integrated the two independent worktrees and checked the signed arm64 Debug app in the hidden Atlas login. The primary fixtures were synthetic 105-second and six-second tones with different titles and saved orders. A third fixture reserved 30 percent at both the top and bottom.

## Picture

The filtered package run passed 61 tests. All 320 build 17 geometry fixtures and the protected macOS 15 render hashes passed. A seeded sweep covered 9,408 combinations of order, zoom, clock size and reserved bands with positive and negative offset requests. It checked 12-pixel separation, frame containment, unchanged export eligibility and zero offsets for layouts that cannot fit. Separate cases covered hidden panes, measured fonts, isolated one-pixel moves, restoring safe zones and the limits a stepper will use in Wave 3.

The two rendering entry points drew identical pixels for a reordered, offset appearance. Clock tests inspected the ink of the labels, the 24-pixel horizontal gap and the color of each reading before, during and after the warning fade. Remaining took the warning color on either side. The hit test covered points a quarter-pixel from both facing waveform extents in both orders and preserved background clicks around an uncontested label.

The integrated headless suite passed 336/336 with FFmpeg, both benchmarks, the slate image and all eight EVS sample exports enabled. After moving the lock notification to the synchronous transition, all 48 queue tests passed again. The final grip color change uses the system secondary label color. Atlas checked its appearance in dark mode, reordered the pane and verified version 0.1 (17) and both executable hashes against the preserved build. Atlas closed each copy and reported an empty cleanup preview.

Escape during a held drag and stationary edge scrolling remain physical-input checks in PX1. Spoken VoiceOver actions remain in PX2, and macOS 27 picture hashes remain in PX3. The reordered MXF viewer comparison is scheduled for P4.1.
